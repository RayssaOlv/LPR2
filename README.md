# Aviso
Para a visualização dos caracteres especiais no código, deve-se utilizar a codificação UTF-8. Caso não tenha a instalada na máquina, adicione a seguinte variável ambiente ao sistema:

Nome da variável: JAVA_TOOL_OPTIONS

Valor da variável: -Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8 -Dsun.stderr.encoding=UTF-8 -Dconsole.encoding=UTF-8
